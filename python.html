Python Basics

Core concepts for Software Developers

1. Introduction
  • Python: High-level, general-purpose language.
  • Setup: Use python --version to verify install.
  • IDE: Visual Studio Code is recommended.
  • Hello World: print("Hello, World!").
2. Syntax & Variables
  • Comments: Use # for single-line.
  • Variable Styles: camelCase, PascalCase, snake_case.
  • Input: name = input("Who are you?").
  • F-Strings: print(f"Hi {name}!").
3. Data Types
int / float Numbers
bool True / False
list Mutable collection
tuple Immutable list
dict Key-value pairs
4. Control Structures
Selection
if / elif / else x if condition else y
Iteration
for item in list: while condition:
5. Advanced Topics

Functions: defined with def.

OOP: class, init, inheritance.

Files: Use with open().

Errors: try / except / finally.

Operator Quick-Ref
Arithmetic: +, -, *, /, //, %, ** Logical: and, or, not Comparison: ==, !=, <,>, <=,>= Membership: in, not in
